# gummy-bear

Godot 4 third-person character project. The bear model is authored in Blender
(`gummy-bear.blend`) and exported to `assets/bear.glb` via `blender/export_bear.py`;
gameplay lives in `scripts/gummy_bear.gd`.

## Agent skills
